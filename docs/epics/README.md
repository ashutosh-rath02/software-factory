# Product requirements and epics

[Documentation](../INDEX.md) / [Product](../product/README.md) / Epics

Epics describe the operator's requirement, analysis, frozen contracts, child work and real-repository
acceptance journey. Start with the [product context](../product/README.md) and
[roadmap](../overview/ROADMAP.md), then choose a requirement from the
[complete epic inventory](../DOCUMENTS.md#epics).

| Need | Source |
|---|---|
| Find every epic and its declared state | [Epic inventory](../DOCUMENTS.md#epics) |
| Prepare an epic | [Existing epic template](_TEMPLATE.md) |
| Understand contract freeze and product acceptance | [Shared workflow](../technical/workflow/WORKFLOW.md#1--product--har-epic-) |
| Follow implementation work | [Tickets](../tickets/README.md) |
| Read validation and acceptance evidence | [Reports](../reports/README.md) |

An epic's declared state and child PASS verdicts do not by themselves prove product acceptance.
Consult the owning journey and its deciding evidence under the existing workflow.
