# Implementation tickets

[Documentation](../INDEX.md) / [Product](../product/README.md) / Tickets

Tickets record bounded server or web work, its acceptance criteria and delivery stages. Use the
[complete ticket inventory](../DOCUMENTS.md#tickets) to find a record; use
[epics](../epics/README.md) to understand its parent requirement.

| Need | Source |
|---|---|
| Find every ticket and its declared state | [Ticket inventory](../DOCUMENTS.md#tickets) |
| Prepare a ticket and follow its standing round | [Existing ticket template](_TEMPLATE.md) |
| Understand stages, QA, landing and verification | [Shared workflow](../technical/workflow/WORKFLOW.md) |
| Inspect verdicts and command captures | [Reports](../reports/README.md) |
| Understand current product progress | [Overview](../overview/README.md), [roadmap](../overview/ROADMAP.md) |

Ticket state is a recorded fact about work. Release readiness and the version currently running
require their own evidence; the [overview](../overview/README.md#evidence-for-progress) distinguishes
those facts. IDs and executable work continue to follow the existing template and workflow.
